# 🤖 Личный Telegram-бот на моделях GLM (Z.ai)

Личный ИИ-бот для двоих: диалог с памятью, ответы «по буквам» в реальном
времени, панель быстрых подсказок, выбор модели кнопкой (есть бесплатные
🆓), распознавание фотографий, белый список пользователей.

## Возможности

| Что | Как |
|---|---|
| 💬 Диалог с памятью | Бот помнит последние 20 сообщений (настраивается); история хранится в SQLite и переживает перезапуск |
| ⌨️ Живая печать | Ответ стримится от Z.ai и печатается в сообщении на глазах — как в ChatGPT. Курсор `▌` исчезает в конце |
| 💡 Быстрые подсказки | Кнопка «💡 Подсказки» или `/prompts`: ужин, свидание, план выходных, анекдот + шаблоны «исправить / перевести / объяснить текст» |
| 🔀 Переключение моделей | `/model` или кнопка «🧠 Модель» — 5 моделей, включая 2 бесплатные |
| 📷 Понимание фото | Пришлите картинку с подписью-вопросом — бесплатная vision-модель GLM-4.6V-Flash опишет её |
| 🔒 Приватность | Отвечает только ID из `ALLOWED_USER_IDS` (вы и ваша жена); данные лежат локально в `bot_data.db` |
| ✂️ Длинные ответы | Автоматически продолжаются следующими сообщениями под лимит Telegram (4096 символов) |
| 🛡 Обработка ошибок | Понятные сообщения при проблемах с API/сетью; корректно ждёт при рейт-лимитах Telegram |
| 👫 Удобно для двоих | Постоянные кнопки внизу экрана — никаких слэш-команд набирать не нужно |

## Установка (5 шагов, ~10 минут)

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → команда `/newbot`
2. Придумайте имя и username бота
3. Сохраните выданный токен вида `1234567890:AAE...`

### 2. Получите API-ключ Z.ai

1. Зарегистрируйтесь на [z.ai](https://z.ai)
2. Меню профиля → **API Keys** → **Create API Key**
3. Скопируйте ключ (показывается один раз). Карта не нужна — бесплатные
   модели работают без пополнения.

### 3. Узнайте свои Telegram ID

Напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш ID
(число). Сделайте это и за вас, и за жену.

### 4. Настройте проект

```bash
cd telegram-glm-bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env            # Windows: copy .env.example .env
```

Откройте `.env` и заполните:

```
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ZAI_API_KEY=ключ_с_z.ai
ALLOWED_USER_IDS=ваш_id,id_жены
```

### 5. Запустите

```bash
python bot.py
```

В консоли появится `Бот запущен`. Откройте бота в Telegram, нажмите
**Start** — и пишите!

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | Приветствие + включить панель кнопок внизу экрана |
| `/prompts` | Панель быстрых подсказок (то же, что кнопка «💡 Подсказки») |
| `/model` | Выбрать модель (кнопки, ✅ — текущая) |
| `/status` | Модель, размер истории, отложенный ввод |
| `/reset` | Очистить историю (начать новую тему) |
| `/help` | Справка |

## Панель быстрых подсказок

Кнопка **«💡 Подсказки»** внизу экрана (или `/prompts`) открывает меню:

- **Готовые запросы** — ответ приходит сразу: 🍳 ужин за 30 минут,
  💡 идея для вечера вдвоём, 📅 план выходных, 🎬 что посмотреть,
  😄 анекдот, 🧘 отдых после работы
- **Шаблоны** — бот попросит прислать текст следующим сообщением,
  затем подставит его в запрос:
  - ✍️ **Исправить текст** — грамматика и стиль
  - 🌍 **Перевести** — автоопределение языка (рус ↔ англ)
  - 🧠 **Объяснить простыми** — как объяснил бы другу, с примером

Подсказку можно дополнить: например, нажмите «🍳 Ужин за 30 минут»,
а потом напишите «только вегетарианское» — бот помнит контекст.

Стриминг можно подкрутить в `bot.py`: `EDIT_INTERVAL` (чаще/реже правки
сообщения, по умолчанию 1.1 сек — безопасно для лимитов Telegram).

## Модели и цены

| Кнопка | Модель | Цена | Кому подходит |
|---|---|---|---|
| 🆓 | `glm-4.7-flash` | $0 | повседневный чат — начинайте с неё |
| 🆓👁 | `glm-4.6v-flash` | $0 | фото и картинки (включается сама для фото) |
| ⚡ | `glm-5.3-flash` | ~$0.00025/сообщение | умнее и быстрее, почти бесплатно |
| 💪 | `glm-5.3-flashx` | ~$0.0007/сообщение | сложные вопросы |
| 🏆 | `glm-5.3` | ~$0.002/сообщение | максимум качества |

Расчёты для типичного сообщения (~700 входных + 300 выходных токенов).

Для платных моделей пополните баланс в консоли Z.ai — $1 хватит на тысячи
сообщений.

## Как добавить фото-модели «понимание» в обычный чат

Ничего делать не нужно: любое фото автоматически уходит бесплатной
vision-модели, а ответ попадает в общую историю диалога.

## Как поменять подсказки под себя

В `bot.py` найдите словарь `PROMPTS` — это обычный Python-словарь:

```python
"fitness": {"label": "🏋️ Тренировка дома",
            "prompt": "Составь 20-минутную домашнюю тренировку без оборудования."},
```

Ключ — короткое имя (уникальное), `label` — надпись на кнопке,
`prompt` — что отправлять модели. Для шаблонов с вставкой текста
используйте `tpl` с `{text}` внутри — как у «✍️ Исправить текст».

## Запуск на сервере 24/7 (по желанию)

На VPS удобно держать бота через systemd:

```bash
sudo tee /etc/systemd/system/glm-bot.service <<'EOF'
[Unit]
Description=GLM Telegram Bot
After=network-online.target

[Service]
User=ваш_юзер
WorkingDirectory=/путь/к/telegram-glm-bot
ExecStart=/путь/к/telegram-glm-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now glm-bot
journalctl -u glm-bot -f    # смотреть логи
```

## Решение проблем

| Проблема | Что делать |
|---|---|
| `❌ Не заполнен .env` | Проверьте, что файл `.env` лежит рядом с `bot.py` и заполнен |
| Бот молчит | Проверьте токен; посмотрите логи в консоли |
| `401` от API | Неверный `ZAI_API_KEY` — создайте ключ заново |
| `404` модель не найдена | Z.ai мог переименовать модель — сверьте ID на docs.z.ai и в списке `MODELS` в `bot.py` |
| `RateLimitError` | Слишком частые запросы — подождите минуту |
| Бот отвечает посторонним | Заполните `ALLOWED_USER_IDS` и перезапустите |
| Ответ печатается рывками | Это нормально: правки не чаще ~1 сек (лимит Telegram). Уменьшите `EDIT_INTERVAL` до 0.8, если хочется чаще |
| Кнопки внизу пропали | Нажмите `/start` — панель вернётся |
| Хочу другой характер бота | Правьте `SYSTEM_PROMPT` в `.env` |
