# 🚀 Деплой бота на облачный хостинг за 30 минут (без консоли)

Инструкция написана для человека без опыта работы с консолью Linux.
Всё делается в браузере: регистрация → загрузка файлов мышкой → бот
работает 24/7. Резервный вариант (Railway/Render) — в конце.

**Почему Amvera?** Русский интерфейс, файлы загружаются прямо через
браузер (Git не нужен), оплата российскими картами, при регистрации
даётся стартовый бонус (~111 ₽ — хватит на первую неделю-две).
Простейшего тарифа (~170–250 ₽/мес) для бота на двоих достаточно;
актуальные цены смотрите на amvera.ru → «Тарифы».

## Что у вас должно быть на руках

- ✅ Токен от @BotFather (строка вида `1234567890:AAE...`)
- ✅ API-ключ с z.ai
- ✅ Два Telegram ID (ваш и жены) — числа, например `123456789`

---

## Шаг 1. Регистрация

1. Откройте **https://amvera.ru** → «Зарегистрироваться»
2. Введите e-mail и пароль (или войдите через GitHub)
3. Подтвердите почту — на счёт упадёт стартовый бонус

## Шаг 2. Создание проекта

1. Нажмите **«Создать проект»**
2. Название: `glm-bot` (латиницей)
3. Тип: **Приложение** (App)
4. Способ загрузки кода: **«Через интерфейс»** (drag-and-drop) — именно
   этот пункт, Git нам не нужен

## Шаг 3. Загрузка файлов

Перетащите в окно загрузки (или выберите мышкой) **4 файла** из папки
проекта `telegram-glm-bot`:

| Файл | Обязательно? | Зачем |
|---|---|---|
| `bot.py` | ✅ да | весь код бота |
| `requirements.txt` | ✅ да | список зависимостей |
| `amvera.yml` | ✅ да | конфигурация хостинга (Python 3.12, запуск `bot.py`, постоянное хранилище `/data`) |
| `.env.example` | ❌ нет | локальная шпаргалка, на хостинге не нужна |

⚠️ **НЕ загружайте файл `.env`** — секреты на Amvera задаются через
веб-панель (следующий шаг). Так безопаснее.

Если интерфейс попросит указать конфигурацию вручную (без `amvera.yml`),
выберите:

- Окружение: **Python**, версия **3.12**
- Инструмент сборки: **pip**
- Путь до requirements: `requirements.txt`
- Скрипт запуска: `bot.py`
- Папка постоянного хранилища: `/data`

Но проще оставить загруженный `amvera.yml` — там уже всё указано.

## Шаг 4. Переменные окружения (самое важное!)

В разделе проекта **«Переменные»** (или «Переменные и секреты») добавьте
5 переменных — нажимайте «Добавить переменную» и заполняйте по одной:

| Имя | Значение | Что это |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | `1234567890:AAE...` | токен от @BotFather |
| `ZAI_API_KEY` | `xAAAA...` | ключ с z.ai |
| `ALLOWED_USER_IDS` | `ваш_id,id_жены` | например `123456789,987654321` |
| `DATA_DIR` | `/data` | чтобы история чатов сохранялась между перезапусками |
| `PYTHONUNBUFFERED` | `1` | чтобы логи появлялись в панели сразу |

❗ Имена переменных — строго как в таблице, большими буквами, без
пробелов вокруг `=`. Значения вставляйте без кавычек.

## Шаг 5. Запуск

1. Нажмите **«Завершить» / «Собрать и запустить»**
2. Статус будет меняться: *«Выполняется сборка» → «Выполняется
   развертывание» → «Успешно развернуто»* (первый раз ~3–5 минут)
3. Если что-то не так — откройте вкладку **«Логи»**: там видно, на чём
   споткнулся бот (почти всегда это опечатка в переменной из шага 4)

## Шаг 6. Проверка

1. Откройте своего бота в Telegram → **Start**
2. Бот должен ответить приветствием и показать кнопки внизу экрана
3. Напишите что-нибудь — ответ напечатается «по буквам» 🎉

Готово: бот работает 24/7, переживает перезапуски и обновления платформы,
история диалогов хранится в постоянном хранилище `/data`.

> 💡 Не пугайтесь, если при открытии выданного платформой домена в
> браузере видна ошибка 502 — бот работает через polling и у него нет
> веб-страницы. Важно, что в Telegram он отвечает.

## Как обновлять бота потом

Вкладка **«Репозиторий»** проекта → выберите файл (например, `bot.py`)
→ отредактируйте в браузере или загрузите новую версию → сохраните →
проект пересоберётся автоматически (или нажмите «Собрать»).

## Стоп / перезапуск

- Кнопка **«Остановить»** в панели — бот засыпает (денежки почти не
  списываются, но и не отвечает)
- **«Запустить»** — просыпается

## Расходы: чего ожидать

## План Б: Railway / Render (если Amvera не подойдёт)

Обе платформы англоязычные, требуют аккаунт GitHub и **иностранную
карту** для оплаты. Схема такая:

1. Создайте репозиторий на GitHub, загрузите туда 4 файла проекта
   (`bot.py`, `requirements.txt`, `amvera.yml` можно не загружать)
2. На платформе: **New → Deploy from GitHub repo** → выберите репозиторий
3. Environment variables: те же 5 переменных из Шага 4 (без `DATA_DIR`
   — на бесплатных тарифах постоянного диска нет, история будет
   обнуляться при каждом обновлении)
4. Start command: `python bot.py` (или платформа определит сама)

⚠️ Нюанс: дешёвые/бесплатные тарифы этих платформ «засыпают» без
трафика (Render Free) — бот просыпается с задержкой до минуты. Для
личного бота на двоих это терпимо, но заметно.

## Если что-то не получается

1. Вкладка «Логи» в панели Amvera — там причина 90% проблем
2. Проверьте переменные: имя с опечаткой или значение с кавычкой —
   классика
3. Поддержка Amvera: support@amvera.ru (укажите имя пользователя и
   название проекта — отвечают быстро)
4. Проблемы со стороны Z.ai (ошибки 401/404) — см. таблицу «Решение
   проблем» в README.md
