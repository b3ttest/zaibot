# Деплой бота на Bothost (bothost.ru)

Bothost — российский хостинг, специализирующийся именно на Telegram-ботах.
Наш проект подходит ему «из коробки», я специально адаптировал код:

* ✅ Bothost **сам подставляет токен** в переменную `TELEGRAM_BOT_TOKEN` — её вообще не нужно настраивать вручную;
* ✅ главный файл `bot.py` Bothost находит **автоматически** (плюс в проекте есть `bothost.json` — подсказка для сборки);
* ✅ база диалогов автоматически пишется в постоянную папку `/app/data` — история не пропадёт после перезапуска или обновления кода.

---

## Шаг 0. Выберите тариф

| Тариф | Цена | Что важно знать |
|---|---|---|
| **Бесплатный** («Start») | 0 ₽ | Бот «засыпает» после простоя (не 24/7), и загрузка zip-архива **недоступна** — только через GitHub (Способ 2) |
| **Активный** («Active»/«Базовый») | ~99 ₽/мес | Бот работает 24/7 без сна, 1 ГБ памяти, можно загрузить zip-архив напрямую |

Актуальные цены смотрите на bothost.ru в разделе тарифов (могут измениться).
Для постоянного пользования вами и женой берите платный «Активный» — 99 ₽/мес,
а нейросеть Z.ai на бесплатных моделях GLM-4.7-Flash вообще не стоит ничего.

## Способ 1. Загрузка zip-архива (самый простой, платные тарифы)

### Шаг 1. Включите загрузку из архива

1. Зайдите на bothost.ru и откройте **Профиль** (bothost.ru/profile.php).
2. В блоке **«Интерфейс»** включите переключатель **«Загрузка бота из архива»**.
3. Нажмите **Сохранить**.

Это одноразовое действие — после него на дашборде появится нужная кнопка.

### Шаг 2. Загрузите архив

1. Откройте **«Мои боты»** (дашборд).
2. Нажмите фиолетовую кнопку **«Загрузить из архива»**.
3. На шаге «Архив» перетащите файл **`telegram-glm-bot.zip`** (он лежит рядом с этой инструкцией) или выберите его на диске.
4. Нажмите **«Далее»**.

### Шаг 3. Настройте бота

Заполните форму мастера:

| Поле | Что вписать |
|---|---|
| **Название** | Любое, например `GLM-ассистент` |
| **Токен бота** | Токен от @BotFather (тот самый длинный `123456789:AA...`) |
| **Язык / шаблон** | Оставьте **«Авто»** |
| **Главный файл** | Оставьте **пустым** — `bot.py` найдётся сам. Можно и указать вручную: `bot.py` |

Нажмите **«Задеплоить»** и **не закрывайте страницу**, пока идёт сборка
(увидите лог: распаковка → установка зависимостей → сборка → запуск).

### Шаг 4. Добавьте переменные окружения

Откройте карточку бота → **настройки** → **«Переменные окружения»** → добавьте по одной:

| Имя | Значение | Зачем |
|---|---|---|
| `ZAI_API_KEY` | ваш ключ Z.ai (вида `sk-...`) | доступ к нейросети |
| `ALLOWED_USER_IDS` | `ваш_id, id_жены` (через запятую, без пробелов) | чтобы посторонние не пользовались ботом |
| `DATA_DIR` | `/app/data` | база диалогов переживёт обновления кода |
| `PYTHONUNBUFFERED` | `1` | логи сразу видны в панели, без задержки |

> **`TELEGRAM_BOT_TOKEN` добавлять НЕ нужно** — Bothost сам подставит токен,
> который вы ввели при создании бота. Код бота поймёт его автоматически.

После добавления переменных **перезапустите бота** (кнопка на карточке бота).

### Шаг 5. Проверьте

1. Откройте Telegram, найдите своего бота, нажмите **Start**.
2. Напишите «привет» — бот должен начать печатать ответ по буквам.
3. Нажмите `/model` — должен прийти список моделей.

Если бот молчит — откройте вкладку **«Логи»** на карточке бота и посмотрите,
что там написано (раздел «Если что-то пошло не так» ниже).

## Способ 2. Через GitHub (работает и на бесплатном тарифе)

Загрузка из архива на бесплатном тарифе недоступна, поэтому код нужно выложить
на GitHub — это бесплатный сайт-«хранилище кода». Всё делается в браузере,
без командной строки.

### Шаг 1. Создайте репозиторий

1. Зарегистрируйтесь на **github.com** (кнопка Sign up).
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Repository name: `telegram-glm-bot`. Выберите **Public** (публичный — это безопасно:
   в коде нет никаких секретов, все ключи вводятся только в Bothost).
4. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы

1. На странице репозитория нажмите ссылку **«uploading an existing file»**.
2. Перетащите файлы проекта: `bot.py`, `requirements.txt`, `README.md`,
   `bothost.json` (остальные — по желанию).
   **Файл `.env` не загружайте никогда** — в нём лежат секреты.
3. Нажмите зелёную кнопку **Commit changes**.

### Шаг 3. Создайте бота на Bothost

1. На дашборде Bothost нажмите **«Добавить бота»**.
2. Заполните:
   * Название — любое;
   * Платформа — **Telegram**;
   * Библиотека — **aiogram**;
   * Токен бота — от @BotFather;
   * Git URL — `https://github.com/ВАШ_ЛОГИН/telegram-glm-bot`;
   * Ветка — `main`.
3. Нажмите **«Создать бота»** и дождитесь окончания сборки в логах.

### Шаг 4. Переменные окружения

Те же четыре переменные, что в Шаге 4 Способа 1:
`ZAI_API_KEY`, `ALLOWED_USER_IDS`, `DATA_DIR=/app/data`, `PYTHONUNBUFFERED=1`.
После добавления перезапустите бота.

## Как обновить бота потом

* **Если заливали архив:** на карточке бота есть кнопка **«залить новый архив»**
  (иконка файла со стрелкой). Загрузите новый zip — при этом сохранятся токен,
  переменные окружения и вся база диалогов в `/app/data`.
* **Если через GitHub:** откройте свой репозиторий → нажмите на файл `bot.py` →
  карандашик (Edit) → вставьте новый код → Commit changes, затем в Bothost
  нажмите «Обновить/Redeploy». Либо удалите файлы и загрузите заново через
  «uploading an existing file».

## Если что-то пошло не так

| Симптом в логах / поведение | Причина и что делать |
|---|---|
| Бот молчит после деплоя | Откройте «Логи». Если там нет ошибок — проверьте, добавлены ли переменные `ZAI_API_KEY` и `ALLOWED_USER_IDS`, перезапустите бота |
| `Conflict: terminated by other getUpdates request` | Бот запущен в двух местах одновременно (например, ещё работает локально или второй контейнер). Остановите вторую копию |
| `Unauthorized` (ошибка 401) | Неверный токен. Проверьте в настройках бота Bothost токен от @BotFather |
| `ModuleNotFoundError: No module named 'aiogram'` | Не установились зависимости. Проверьте, что `requirements.txt` есть в архиве/репозитории, и пересоберите |
| `can't open file 'bot.py'` | Неверно указан главный файл — в настройках бота укажите `bot.py` |
| Бот «забыл» диалоги после обновления | Не задана `DATA_DIR=/app/data` — добавьте переменную и перезапустите |
| Бот работает днём, а потом перестаёт отвечать | Это «спящий режим» бесплатного тарифа. Переходите на платный «Активный» |
| Сборка падает, в логе ошибка pip | Поддержка: напишите в Telegram **@bothostru** — отвечает быстро |
